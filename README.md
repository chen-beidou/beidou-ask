# beidou-ask

面向 AI 视频生成的电影化分镜 Skill。它把剧本、场景构思和现有美术资产整理为逐镜头、带时间戳、可直接投喂视频模型的完整提示词。默认采用不压缩交付：所有适用规则在文字阶段落实为具体机位、动作、状态、光影、声音和衔接安排，不把“遵守规则”的判断留给视频模型。

当前版本：`v3.3.0`

## 支持范围

- Seedance 2.x
- Wan 3.0
- MiniMax H3
- 15 秒、30 秒及按当前模型上限拆分的连续 Clip
- 16:9 横屏和 9:16 竖屏
- 对白、情绪、对峙、打斗、追逐和混合场景
- 逐字保留剧本台词
- 角色、道具、空间、情绪与跨集连续性
- 默认完整、不压缩、可逐项审计的提示词
- 30°机位变化、180°轴线、景别变化和焦点关系写入具体镜头
- 每镜明确状态变化、承接、画面动作、摄影机、细节光影、台词声音和镜头落点
- 段尾定格帧直接定义下一段起幅
- 分镜结构自动校验

## 默认输出结构

每个独立生成段都是一份自包含提示词，按以下顺序交付：

1. 段落标题、时长、画幅、目标模型、对应剧本与出场人物
2. `素材说明`
3. `一句话概述`
4. `具体情节`
   - `初始状态`
   - 带时间戳的逐镜头执行字段
   - `段尾定格帧＝下一段起幅`
5. `全局补充`

默认不会因为篇幅较长而删除规则证据。只有用户明确要求时，才会在保留完整版的前提下另给“精简衍生版”。

## 安装

下载仓库中的最新版 `beidou-ask.zip`，将其作为 Skill 导入；也可以直接复制仓库内除 `README.md` 和压缩包以外的技能文件。压缩包与当前版本的规则、样例、验证器和界面元数据同步。

Skill 的主入口是 [`SKILL.md`](SKILL.md)。

## 校验分镜文件

安装 Node.js 后运行：

```text
node scripts/validate-storyboard.mjs <storyboard.md>
```

校验器同时识别新版完整排版与旧版兼容格式，并检查段落结构、时间戳连续性、景别、机位或运镜、结尾状态、全局补充和部分资产引用问题。

## 输出边界

本 Skill 只生成分镜和视频模型提示词，不生成人物或场景美术资产，不在未检视成片时宣称生成效果已经验证。
