# Director styles (可选风格化滤镜)

A director style is a **unified lens** that coerces every shot's composition, camera, light, and color into one consistent look without changing story facts, dialogue, or beats. It is optional and applied only on request. Unlike `特殊风格化` (dream / memory / surveillance / comic / game-UI), a director style is a *normal* render philosophy, not a reality warp.

## Rules

- Style is a **lens, not a rewrite**: narrative facts, dialogue, blocking logic, and continuity are unchanged.
- Apply **one** style per Clip/project; do not mix two looks.
- State the style once in `全局风格锁定` (optional line), not per shot.
- If the target model resists the style (e.g. H3 struggles with anamorphic color), degrade the style cues to the layer the model obeys.

## Applying it

In a shot, the style changes **how** you choose, never **what** you must show. Example — a shot that must land "she is trapped":

- 中性: 俯拍、前景遮挡、门框入画。
- 库布里克: 广角单点透视把她压进门的正中心，左右墙强对称，冷白光切一道硬边。
- 希区柯克: 窥视机位从高提处俯视，她缩在画面底角，虚空压她。
- 王家卫: 她靠窗，霓虹碎在她脸上，飘移手持让画面微微晕。

Same fact, three different weights. Pick the one that serves the scene's tone.
