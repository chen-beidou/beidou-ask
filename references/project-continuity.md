# Project continuity

Use for episodic work or any project whose state survives beyond one delivery.

## Project configuration

Record model, duration, ratio, medium, output language, dialogue policy, recurring assets, and global style once. Reuse it in later episodes unless the user changes a field.

## Cross-episode state

Track only durable facts that affect later shooting:

- character: injury, wardrobe, emotional baseline, availability
- prop: owner, hand, condition, loss or transfer
- location: damage, access, light, weather, persistent marks
- relationship: alliance, rupture, knowledge, leverage, death

At the end of an episode, retain only new durable changes. At the next episode, load only the facts relevant to its scenes. Never silently restore a destroyed location, lost prop, persistent injury, or changed relationship.

Do not write or update project files unless the user requested file output or authorized continuity persistence.
