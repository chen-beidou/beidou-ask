# Spatial power (空间权力站位)

A spatial-position block is a *power diagram*, not a list of left/right coordinates. Before writing positions, decide who has power and where power shifts. These are binaries — pick one side per beat.

## The binaries

| Rule | What it tells the audience |
|---|---|
| 谁动、谁静止 | 静止是权力。必须移动的一方 = 有所求、处在下位的一方。 |
| 谁控制出口 | 挡在对方与门/出口之间的人在下达判决；远离出口的一方在请求许可。 |
| 谁高谁低 | 在高处者俯视为王；被俯视者被压制。平地用同一水平线则均势。 |
| 谁被框住（门框/窗棂/柱/卡在取景器边缘内） | 被建筑"拘禁" ≈ 空间在审判他、他已被困住。 |
| 谁孤立 / 谁被围 | 一人被多人包围 = 弱势；一人独处但身影巨大 = 他的世界只剩自己。 |
| 谁正对 / 谁背对 | 对话中转身 90–180° 而对方仍在说 = 拒绝、漠视。 |
| 谁先走近 | 未经邀请从社交距离切入私人距离 = 侵入；对方后退则侵入者赢下这一拍。 |
| 对称 / 不对称 | 两人位置完全对称（各自垂直三分位）= 契合、正缘；不对等 = 不合、失衡。 |

## Camera angle encodes power

- 角色占上风 → 镜头**仰视**他；角色处下风 → 镜头**俯视**他。
- 持平对话 → 平视（The Godfather 全片平视，观众"如在屋内"，唯顶拍给关键时刻神性重量）。

## Focal-character staging check (per Clip)

Every `空间站位` block must answer — at least three of these explicitly:

1. 谁在画面上位/高位，谁在下位/低位？(高度差)
2. 谁静止不动，谁必须移动？(谁有所求)
3. 谁控制出口/门前位？(谁在审判)
4. 谁背对谁，谁正对谁？(朝向与拒绝)
5. 谁被门框/窗棂/柱/取景器边缘框住？(谁被困/被审判)
6. 谁被包围，谁孤立？(One vs Many)
7. 两人站位对称还是不对称？(契合 vs 失衡)
8. 动作轴：武器/道具归谁，手用哪只，攻击来自哪一侧？(继承自原站位，必须保留)

## Example

> "她要什么，她就得动；他不给，他就站着。她站在他和门之间——这场谈话是他来求她，不是她求他。他始终比镜头低半头，他开口时视线偏下。门框收在她两侧，像把她钉在画幅里。"

Nothing here is dialogue — it is all readable in a single held frame.
